# Christmas Tree for your desktop

A decorated Christmas tree that sits on your Windows desktop, with twinkling lights, presents, a countdown to Christmas, an optional dog and cat, and a little elf who turns up somewhere new each day.

## Getting started

1. Save the file somewhere it can stay, such as your Desktop or your Documents folder.
2. Double-click it.
3. The first time, Windows may show a blue box saying **"Windows protected your PC"**. That is because this is a home-made program, not one from a big company. Click **More info**, then **Run anyway**. You only need to do this once.

The tree appears on your desktop, and a small tree icon appears near the clock in the bottom-right corner of the screen (you may need to click the little **^** arrow to see it).

## Using it

- Click the tree to turn the lights on or off.
- Drag the tree to move it. Drag the gold corner to make it bigger or smaller.
- Right-click the tree for everything else: tree type, light colour and pattern, toppers, a skirt or stand, presents, snow, the countdown, a dog or a cat, the wandering elf, and Settings.
- In Settings you can make it start when Windows starts, and set a bedtime when the lights turn off by themselves.

## Removing it

Right-click the tree icon near the clock and choose **Exit**, then delete the `.exe` file. If you turned on "Start with Windows", turn it off in Settings first. Your choices are kept in a folder called `ChristmasTree` inside `%AppData%`, which you can delete too.

It does not use the internet and does not collect anything.
